# Smart Parking Management System

## Project Overview

The Smart Parking Management System is a web-based application that helps users find and book available parking slots efficiently.

The system prevents multiple users from booking the same parking slot by using database transactions and proper booking validation.

## Key Features

- User registration and login
- JWT-based authentication
- View parking lots
- View available parking slots
- Book a parking slot
- Manage bookings
- Payment management
- Booking status tracking
- Audit logging
